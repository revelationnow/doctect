**Smart guides** pull what you're moving into line with what's already on the page. Drag an object near another one's left, right, top or bottom edge, or its centre, and it snaps into line; a pink guide shows which edges lined up, with the gap to that object in points. The page's edges and centre work the same way.

- **Equal spacing** — dragging between two objects centres it between them; dragging past a row repeats a gap that's already there. Brackets show the matching gaps.
- **Matching sizes** — while resizing, the side you're dragging snaps to another object's width or height; the label (`= 120`) sits on the shape you're resizing. A rectangle or ellipse whose width and height come within reach of each other snaps square (or round), labelled on both sides; that takes priority over matching another object's size.
- **Every visible layer counts**, locked ones included, so a locked background frame is a handy alignment reference. Hidden layers never pull.

Hold `kbd:Alt` (`kbd:Option` on a Mac) while dragging to move freely — press it once the drag is under way, since an Alt-click on its own selects through stacked shapes. Turn guides off in the toolbar's **Snapping options** (the small arrow just past the magnet and Show Grid icons), or on a tablet or phone under **More actions → Canvas**. The setting is saved with the project.

When Snap to Grid is also on, the grid always wins: the object's edge lands on a grid line, and guides only pull it to a line that also lines up with another object or the page. A guide that would leave it off the grid is ignored. See [Snap to Grid](/docs/reference/snap-to-grid).
