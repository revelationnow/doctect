Just left of the zoom controls sit **Snap to Grid** (the magnet), **Show Grid**, and a small arrow that opens **Snapping options**. Turning Snap on always turns Show Grid on too, so you can see the grid you're snapping to; turning Snap off leaves the grid as you had it.

With Snap on, a moved object's left and top edges land on grid lines, a resized object's dragged edge lands on a line, and new shapes start and end on lines. Choose the size — **1 to 200 pt**, default **10 pt** — in **Snapping options**, or under **More actions → Canvas** on a tablet or phone. It's saved with the project. When you zoom far out the grid is drawn more sparsely so it stays readable, but snapping still uses the size you chose.

Snap also changes nudging: an arrow key moves the selection to the next grid line, `kbd:Shift+Arrow` ten grid lines. [Smart guides](/docs/reference/smart-guides) win over the grid when one is within reach; hold `kbd:Alt` to move without either.

See [Moving around the canvas](/docs/editor/canvas-basics#moving-around-the-canvas).
